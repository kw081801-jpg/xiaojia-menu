# 小家菜单 · 动态菜单页

参考「99 Bar 酒单」的结构做的家庭菜单页：开场封面 → 分类浏览 → 点开看食材做法 → 抽签决定今晚吃什么。

**六套主题随时切换**，每道菜都配了图。纯静态，双击 `index.html` 就能打开，不需要装任何东西、不需要服务器。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面本体（结构 + 样式 + 交互 + 主题），一般不用动 |
| `menu-data.js` | 菜单数据源，改菜、加菜、改标题都在这里 |
| `images/` | 菜品配图 + 封面图（WebP，共约 1.3 MB） |

## 六套主题

右上角圆形的「◐」按钮切换，选择会记在浏览器里，下次打开还是这套。

「角落」这套是奶油白配薄荷绿：卡片圆角、虚线边框、奶油黄的角标，标题换成圆体（站酷快乐体）。小家伙分布在这些地方：

- 卡片左上角一条薄荷和纸胶带
- 分类标题后面一个小熊头
- 页面左下、右下角各有一只从屏幕边缘探头的猫和炸猪排（随滚动固定）
- 封面底部一排五个（白熊、珍珠、绿蜥蜴、猫、炸猪排），左右两侧还有猫和猪排
- 详情弹窗左上角蹲一只小熊
- 搜不到菜时的空状态、抽签页的牌面两侧也各有一两只
- 页脚一排小号

窄屏会自动收：≤760px 先收起封面两侧和屏幕角落的探头；≤600px 封面那排缩小、胶带变窄、圆角和字号降一档；≤420px tab 再缩一档。360 / 390 / 512 / 768 / 1440 五个宽度都实测过，不出现横向滚动。

| 主题 | 风格 | 底色 / 主色 |
| --- | --- | --- |
| 夜宴 Night | 黑金，安静夜里的餐厅感 | `#0b0a0e` / `#e2cfa6` |
| 米纸 Paper | 暖白纸感，像手写菜谱 | `#f5efe4` / `#b2643a` |
| 抹茶 Matcha | 墨绿配浅茶绿，清爽 | `#0f1e18` / `#cfe3c0` |
| 酒红 Wine | 勃艮第酒红，适合晚上 | `#180a10` / `#f0c8bf` |
| 晨雾 Dawn | 冷白灰蓝，白天看最舒服 | `#eef1f5` / `#2f5b68` |
| 角落 Sumikko | 奶油白 + 薄荷绿，圆角贴纸感，角落小伙伴探头 | `#fdf7ee` / `#7fb8ae` |

想加自己的主题：在 `index.html` 的 `<style>` 里复制一段 `[data-theme="xxx"]{...}`，改变量；
再在 JS 里的 `THEMES` 数组加一条 `{ key, label, en, color, sw }` 就行。

## 改内容

打开 `menu-data.js`：

- `MENU_SETTINGS`：首页标题、副标题、封面文案、分类 tab
- `MENU_ITEMS`：每道菜

一道菜的核心字段：

```js
{
  name: "番茄炒蛋",        // 菜名
  en: "Tomato & Egg",     // 英文名，可留空
  img: "images/tomato-egg.webp", // 配图，留空则显示菜名首字的圆形印章
  cat: "home",            // 分类 key，对应 MENU_SETTINGS.categories
  flavor: "酸甜 · 下饭",   // 卡片右侧的口味
  time: "10 分钟",         // 耗时
  level: "新手",           // 新手 / 顺手 / 慢炖
  serve: "2 人份",
  tag: "招牌",             // 左上角角标，可留空
  intro: "一句话介绍",
  ingredients: ["番茄 2 个", "鸡蛋 3 个"],
  steps: ["第一步…", "第二步…"],
  tips: "小贴士，可留空",
  hidden: false            // true 就不显示
}
```

配图建议 **4:3 或 16:9**、宽 900px 左右、WebP 格式（体积小、清晰度够）。
没有配图的菜会自动退回到「菜名首字」的圆形印章，不会破版。

新增分类：在 `MENU_SETTINGS.categories` 里加一条 `{ key, label, en, note }`，
再在 `MENU_SETTINGS.tabs` 里加一条同名 tab 即可。

## 功能

- 开场封面（实拍大图 + 深色渐层），点按钮或空白处进入
- 顶部搜索：菜名 / 英文名 / 口味 / 食材都能搜
- 分类 tab（全部、家常、汤羹、主食、甜品、饮品）+ Surprise
- 分类锚点导航：滚动时自动高亮当前分类，点圆点跳转
- 分组标题可点击折叠，滚动时吸顶
- 卡片配图，点开看大图 + 食材清单 + 做法步骤 + 小贴士（Esc 或点遮罩关闭）
- Surprise：先选一类，抽一张塔罗牌翻面，翻到菜直接看图
- 点击音效用 Web Audio 合成，可关（会记住选择）
- 手机 / 平板 / 桌面自适应，支持 `prefers-reduced-motion`

## 说明

- 字体优先用 Google Fonts（Cormorant Garamond / Noto Serif SC），断网时自动退到系统宋体，排版不会崩。
- 配图是本机用 Stable Diffusion（majicMIX realistic）批量生成的，统一「深色木桌 + 暖光 + 近景」的路子，所以 25 张放一起色调一致。想换成自己拍的，按上面的字段替换 `images/` 里的文件即可。
- 所有数据都在本地，不联网、不上报（字体以外没有任何外部请求）。

## 关于角色形象

页面里的小家伙（白熊、炸猪排、珍珠、绿蜥蜴、猫）**不是三丽鸥的官方素材**，没有用任何官方立绘、贴纸或 Logo，全是按印象手写的 SVG 仿造型（圆头、点眼、腮红、和纸胶带配色那一套）。它们只借了「角落生物」的风格气质，比例和线条都是自己画的。

想换成官方形象，可以把 PNG 放进 `images/`（或新建 `assets/friends/`），再把页面里 `<svg class="sk"><use href="#sk-xxx"></use></svg>` 换成 `<img src="...">` 即可，尺寸沿用 `.sk` 那组 clamp 规则。
