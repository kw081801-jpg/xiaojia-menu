# 小家菜单 · 动态菜单页

**在线地址：<https://kw081801-jpg.github.io/xiaojia-menu/>**（GitHub Pages，全球可访问，手机直接开）

参考「99 Bar 酒单」的结构做的家庭菜单页：开场封面 → 分类浏览 → 点开看食材做法 → 抽签决定今晚吃什么。

**六套主题随时切换**，每道菜都配了图。纯静态，双击 `index.html` 就能打开，不需要装任何东西、不需要服务器。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面本体（结构 + 样式 + 交互 + 主题），一般不用动 |
| `menu-data.js` | 菜单数据源，改菜、加菜、改标题都在这里 |
| `images/` | 菜品配图 + 封面图（WebP，共约 1.3 MB） |

## 六套主题

右上角圆形的「◐」按钮切换，选择会记在浏览器里，下次打开还是这套。

「角落」这套是奶油白配薄荷绿：卡片圆角、虚线边框、奶油黄的角标，标题换成圆体（站酷快乐体）。小家伙分布在这些地方：

- 卡片左上角一条薄荷和纸胶带
- 分类标题后面一个小熊头
- 页面左下、右下角各有一只从屏幕边缘探头的猫和炸猪排（随滚动固定）
- 封面底部一排五个（白熊、珍珠、绿蜥蜴、猫、炸猪排），左右两侧还有猫和猪排
- 详情弹窗左上角蹲一只小熊
- 搜不到菜时的空状态、抽签页的牌面两侧也各有一两只
- 页脚一排小号

窄屏会自动收：≤760px 先收起封面两侧和屏幕角落的探头；≤600px 封面那排缩小、胶带变窄、圆角和字号降一档；≤420px tab 再缩一档。360 / 390 / 512 / 768 / 1440 五个宽度都实测过，不出现横向滚动。

想加自己的主题：在 `index.html` 的 `<style>` 里复制一段 `[data-theme="xxx"]{...}`，改变量；
再在 JS 里的 `THEMES` 数组加一条 `{ key, label, en, color, sw }` 就行。

## 改内容

打开 `menu-data.js`：

- `MENU_SETTINGS`：首页标题、副标题、封面文案、分类 tab
- `MENU_ITEMS`：每道菜

一道菜的核心字段：

```js
{
  name: "番茄炒蛋",        // 菜名
  en: "Tomato & Egg",     // 英文名，可留空
  img: "images/tomato-egg.webp", // 配图，留空则显示菜名首字的圆形印章
  cat: "home",            // 分类 key，对应 MENU_SETTINGS.categories
  flavor: "酸甜 · 下饭",   // 卡片右侧的口味
  time: "10 分钟",         // 耗时
  level: "新手",           // 新手 / 顺手 / 慢炖
  serve: "2 人份",
  tag: "招牌",             // 左上角角标，可留空
  intro: "一句话介绍",
  ingredients: ["番茄 2 个", "鸡蛋 3 个"],
  steps: ["第一步…", "第二步…"],
  tips: "小贴士，可留空",
  hidden: false            // true 就不显示
}
```

配图建议 **4:3 或 16:9**、宽 900px 左右、WebP 格式（体积小、清晰度够）。
没有配图的菜会自动退回到「菜名首字」的圆形印章，不会破版。

新增分类：在 `MENU_SETTINGS.categories` 里加一条 `{ key, label, en, note }`，
再在 `MENU_SETTINGS.tabs` 里加一条同名 tab 即可。

## 功能

- 开场封面（实拍大图 + 深色渐层），点按钮或空白处进入
- 顶部搜索：菜名 / 英文名 / 口味 / 食材都能搜
- 分类 tab（全部、家常、汤羹、主食、甜品、饮品）+ Surprise
- 分类锚点导航：滚动时自动高亮当前分类，点圆点跳转
- 分组标题可点击折叠，滚动时吸顶
- 卡片配图，点开看大图 + 食材清单 + 做法步骤 + 小贴士（Esc 或点遮罩关闭）
- Surprise：先选一类，抽一张塔罗牌翻面，翻到菜直接看图
- 点击音效用 Web Audio 合成，可关（会记住选择）
- 手机 / 平板 / 桌面自适应，支持 `prefers-reduced-motion`

## 说明

- 字体优先用 Google Fonts（Cormorant Garamond / Noto Serif SC），断网时自动退到系统宋体，排版不会崩。
- 配图是本机用 Stable Diffusion（majicMIX realistic）批量生成的，统一「深色木桌 + 暖光 + 近景」的路子，所以 25 张放一起色调一致。想换成自己拍的，按上面的字段替换 `images/` 里的文件即可。
- 所有数据都在本地，不联网、不上报（字体以外没有任何外部请求）。

## 打开速度（国内手机流量）

页面现在**不请求任何境外资源**，字体、样式、图片全部同域加载：

| 项 | 处理 |
| --- | --- |
| 字体 | 三份自托管 woff2：Cormorant（拉丁衬线，约 60KB / 用不到会自动跳过）+ 站酷快乐体中文子集 76KB（只含页面用到的 753 个字符） |
| 字体子集 | 改了菜名出现生僻字时，跑 `python scripts/subset-fonts.py` 重新生成 |
| 图片 | 每张图两档：`images/` 900px（桌面）与 `images/sm/` 560px（手机），用 `srcset` 自动挑 |
| 首屏 | 首屏只加载封面 + 可见卡片，约 250KB；整页滚动看完约 1.1MB |
| 外链 | 0 个（原先的 Google Fonts 已移除，那是国内最容易卡住的一环） |

托管在 GitHub Pages（Fastly 节点）。大陆可以直连（阿里/腾讯 DNS 均解析到 185.199.108-111.153，没有被污染），4G 下一般 1–3 秒打开，偶发慢的时候换 Wi-Fi 或重试即可。

**要保证"永远秒开"**，只能上国内节点：阿里云 OSS / 腾讯云 COS / 又拍云 / 腾讯 EdgeOne Pages 的静态托管都行，把本目录整个传上去即可（不需要构建）。这类服务要实名账号，给我密钥我可以直接推上去。

## 前后端分开：管理台 + 点菜

现在有两套用法，同一份页面：

**A. 纯静态（现在的 GitHub Pages）** — 只读菜谱，数据来自 `menu-data.js`，没有点菜按钮，谁都能看，改菜要改文件再推。

**B. 带后端（本地 / 自己的服务器）** — 多出两个能力：管理员在 `admin.html` 里增删改菜谱、上传图片；家里人打开前台可以「加入今晚菜单」并提交，订单落到管理台。

```
浏览器（前台）  ──GET  /api/menu────▶   server.py ── SQLite (data.db)
浏览器（管理台）──POST /api/orders──▶     ↑
                ──CRUD /api/items ──▶     └─ images/uploads/
```

### 跑起来

```bash
python server.py                 # 默认 0.0.0.0:8080
python server.py --port 9000     # 换端口
```

打开：

- 前台 <http://127.0.0.1:8080/>
- 管理台 <http://127.0.0.1:8080/admin.html>，默认密码 `xiaojia`

进去先点「从 menu-data.js 导入初始菜单」，会把现有的 25 道菜写进数据库，之后就在管理台里改。

### 管理台能做的

- 菜谱：新增 / 编辑 / 删除，字段和 `menu-data.js` 完全一样（菜名、分类、口味、耗时、难度、份量、食材、步骤、贴士、配图）
- 配图：直接选本地图片上传，自动存到 `images/uploads/`（png / jpg / webp，6MB 以内）
- 订单：看谁点了什么、备注、提交时间，可标记「已做」或删除，新订单会在 tab 上显示数字
- 页面设置：站名、副标题、封面文案、按钮文案，改完前台立刻生效（读的是接口）

### 前台的点菜流程

1. 点开任意一道菜 → 弹窗里有「＋ 加入今晚菜单」
2. 底部浮出「已选 N 道」，点开能看到清单、填「谁点的」和备注
3. 提交 → 写进数据库 → 管理台「订单」里出现，标题上有新单数字

没接后端时（比如 GitHub Pages），这些按钮不出现，页面行为和以前完全一样。

### 安全与运维

- 管理密码用环境变量覆盖：`XJ_ADMIN_PASSWORD=你的密码 python server.py`
- 登录态是 HttpOnly Cookie，有效期 7 天，重启服务即失效
- 数据全在 `data.db` 一个文件里，备份它就是备份全部；删掉等于恢复出厂
- **放到公网一定要配 HTTPS**（Nginx / Caddy 反代 + 证书），否则密码和 Cookie 是明文
- 需要开机自启的话，Windows 用计划任务，Linux 用 systemd，命令都是 `python server.py`
